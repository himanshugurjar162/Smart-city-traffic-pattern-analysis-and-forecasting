# Smart City Traffic Pattern Analysis & Forecasting

Student-level project for analyzing and forecasting hourly traffic at 4 city
junctions, accounting for weekday/weekend and holiday/special-occasion
effects — to support smart-city traffic management and infrastructure
planning.

## Folder structure
```
traffic_project/
├── data/
│   ├── generate_traffic_data.py     # creates a realistic sample dataset (offline)
│   ├── traffic_data.csv             # raw dataset (generated)
│   └── traffic_data_cleaned.csv     # cleaned + feature-engineered dataset (generated)
├── scripts/
│   ├── week1_setup_and_exploration.py
│   └── week2_cleaning_feature_engineering_eda.py
├── outputs/
│   └── screenshots/                 # PNG screenshots/plots generated by the scripts
├── requirements.txt
└── README.md
```

## How to run on your machine

1. **Install Python 3.9+** if you don't already have it.

2. **Create a virtual environment (recommended)**
   ```bash
   python -m venv venv
   source venv/bin/activate        # on Windows: venv\Scripts\activate
   ```

3. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

4. **Generate the dataset** (run once)
   ```bash
   python data/generate_traffic_data.py
   ```
   This creates `data/traffic_data.csv` with hourly vehicle counts for
   4 junctions from Nov 2015 to Jun 2017, including some missing values
   and duplicates on purpose so the cleaning steps have real work to do.

   > **Using the real dataset instead:** if you'd rather use actual data,
   > download the public "Traffic Prediction Dataset" from Kaggle
   > (search that exact name, by fedesoriano) and save it as
   > `data/traffic_data.csv` with the same columns
   > (`DateTime, Junction, Vehicles, ID`) — skip this generation step.

5. **Run Week 1 (setup & initial exploration)**
   ```bash
   python scripts/week1_setup_and_exploration.py
   ```
   Prints dataset shape, sample rows, missing-value/duplicate checks, and
   saves screenshots to `outputs/screenshots/`.

6. **Run Week 2 (cleaning, feature engineering & EDA)**
   ```bash
   python scripts/week2_cleaning_feature_engineering_eda.py
   ```
   Cleans the data, adds date-time/holiday features, saves
   `data/traffic_data_cleaned.csv`, and generates 4 EDA plots into
   `outputs/screenshots/`.

7. **Run Week 3 (model building & evaluation)**
   ```bash
   python scripts/week3_model_building_evaluation.py
   ```
   Splits each junction's data chronologically (last 15% held out as
   test), trains Linear Regression and Random Forest models per junction,
   evaluates them with MAE/RMSE, and saves a results table, a model
   comparison chart, and an actual-vs-predicted plot into
   `outputs/screenshots/`.

8. **Run Week 4 (tuning, final comparison & infrastructure insights)**
   ```bash
   python scripts/week4_tuning_final_insights.py
   ```
   Tunes the Random Forest model per junction (small grid search
   validated on a held-out slice of the training period), compares it
   against the Week 3 baselines on the test set, extracts feature
   importances (what drives traffic at each junction), and builds a
   peak-hour summary table to support infrastructure recommendations.
   Saves 4 more screenshots into `outputs/screenshots/`.
